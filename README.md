# 德州扑克 (Texas Hold'em Poker) - 单人练习 & 局域网联机对战版

精美、严谨且富有沉浸感的德州扑克游戏。既支持**离线单人单机练习**，也支持**同一局域网（Wi-Fi）下多端多好友实时联机对战**，并支持房主**一键补齐人机**！

---

## 🎮 快速开始

### 方式零：Windows 桌面双击直接启动（最便捷）

项目根目录下已包含专属图标的启动程序，无需打开命令行：
- **`德州扑克.exe`**：双击直接启动局域网联机服务端并**自动在默认浏览器中打开游戏**。
- **`启动游戏.bat`**：批处理启动脚本，双击同样可以一键唤起服务。

---

### 方式一：命令行启动局域网联机对战模式 (Multiplayer)

1. **安装依赖并启动联机服务器**：
   在终端运行：
   ```bash
   npm install
   npm start
   # 或
   node server.js
   ```

2. **终端将自动输出本机访问与局域网 IP 地址**：
   ```
   ================================================================
     ♠ 德州扑克局域网对战联机服务器已启动 ♠
   ================================================================
   - 本机访问地址:    http://localhost:3000
   - 局域网好友访问:  http://192.168.1.105:3000
   ================================================================
   ```

3. **进入与分享**：
   - **房主**：浏览器打开 `http://localhost:3000`，点击顶部 **【🌐 联机大厅】** -> **【创建新房间】**，生成 4 位房间号（如 `#8888`）。
   - **好友加入**：同 Wi-Fi 局域网下的好友在手机或电脑浏览器中打开提示的局域网地址（如 `http://192.168.1.105:3000`），输入房间号搜索或直接在活跃列表中点击加入。
   - **一键补齐人机**：房主在房间等待区点击 **【🤖 一键补齐人机】**，空余座位将自动填满各具性格的经典 AI（老张、狂热阿飞、老实陈叔、铁壁李哥、智者艾玛）！
   - **开始对战**：房主点击 **【🚀 开始游戏】**，全员同步发牌开局！

---

### 模式二：单人离线练习模式 (Solo Practice)

直接双击在浏览器中打开 `index.html`，无需启动服务器即可立即开始与 5 位电脑 AI 对弈练习。

## 🌟 核心特性

1. **局域网联机与房间系统**
   - **轻量权威服务端**：基于 Node.js 与 WebSocket，自动探测并输出局域网 IP，手机、平板、电脑跨设备畅玩。
   - **房间号搜索与大厅列表**：生成高可读 4 位房间号，支持精确搜索，也支持大厅浏览活跃房间一键直达。
   - **🤖 一键补齐人机**：支持任意真人玩家组合（如 1~5 人），房主一键为剩余空位分配性格各异的 AI，随时随地开局。
   - **🛡️ 手牌防作弊安全**：服务端权威发牌脱敏，每位玩家只能看见自己的两张私有底牌，摊牌阶段前绝不泄露对手手牌。
   - **自适应主视角（Hero Perspective）**：无论玩家加入哪一个座位，在自己的屏幕上始终优雅居于牌桌正下方核心视角。

2. **严谨的德州扑克规则引擎**
   - 大小盲注自动扣除、庄家位（Dealer Button）每局轮转。
   - 翻牌前 (Pre-Flop)、翻牌圈 (Flop)、转牌圈 (Turn)、河牌圈 (River)、摊牌 (Showdown)。
   - **精确 7 选 5 最佳牌型评估器**：支持皇家同花顺、同花顺、四条、葫芦、同花、顺子（含 A-2-3-4-5 轮转顺子）、三条、两对、一对、高牌及踢脚牌（Kickers）精准比对。
   - **多级边池算法 (Side Pot Calculation)**：准确处理多名玩家不同注额 All-in 时的底池拆分与派彩。

3. **5 位性格各异的电脑 AI 对手**
   - 🦈 **老张 (紧凶型 - TAG)**：只玩高胜率起手牌，一旦拿到强牌会激进加注施压。
   - 🔥 **狂热阿飞 (松凶型 - LAG)**：极高入池率与加注频率，酷爱诈唬与全下。
   - 🐟 **老实陈叔 (跟注站 - Station)**：喜欢看底牌，极少弃牌，偏好被动跟注，极难被诈唬下桌。
   - 🗿 **铁壁李哥 (石佛 - Rock)**：极度严苛，只玩顶级起手牌，出注必有大牌。
   - 🦉 **智者艾玛 (GTO平衡型 - Pro)**：基于底池赔率（Pot Odds）与数学期望（EV）进行理性决策。
   - AI 带有动态思考发言气泡与头像旁加注金额弹出动画。

4. **精致赌场级视觉与音效体验**
   - 筹码、底池图标全矢量 SVG 化，拒绝字符豆腐块乱码。
   - Web Audio API 原生合成音效：发牌滑动声、筹码碰撞声、敲桌过牌声、全下震撼音、获胜胜利和弦。
   - 实时手牌成色牌力辅助提示（金色黑桃徽章）。
   - 快捷加注按钮组（Min、2.5BB、半池、满池、全下）与平滑滑块。
